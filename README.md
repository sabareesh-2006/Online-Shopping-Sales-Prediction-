# Online Shopping Sales Prediction Using Machine Learning

## Project Overview

This project focuses on predicting total sales in an online shopping business using Machine Learning algorithms. The dataset contains 100 records and 20 columns related to online shopping sales.

## Objectives

- Analyze online shopping sales data.
- Perform data preprocessing and cleaning.
- Handle missing values and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Apply Machine Learning regression algorithms.
- Predict total sales based on input features.

## Dataset

- Dataset: Online Shopping Sales Dataset
- Records: 100
- Original Columns: 20
- Target Variable: "Total_Sales"
- File Format: CSV

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regression
- Support Vector Regression (SVR)
- Polynomial Regression
- Elastic Net Regression
- K-Nearest Neighbors (KNN) Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Project Files

- "Online_Shopping_Sales (1).ipynb" – Project implementation and code.
- "online_shopping_sales_100_rows_20_columns.csv" – Dataset used for analysis and prediction.

## Conclusion

This project demonstrates how Machine Learning regression algorithms can be used to analyze online shopping data and predict total sales.
